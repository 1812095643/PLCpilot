# 文档工作区、生图与可选 OfficeCLI 实施计划

## 目标与边界

在 PLC Pilot 内打开右侧文件工作区，对话和输入框一同收窄。使用现有 Tauri + Vue，文档核心由 Rust 执行，不引入 Electron、兼容 IPC 或第二套模型凭据。OfficeCLI 是按需安装、可停用、可切换的外部引擎。不修改已有项目模式与会话语义，不默认推送或发版。

## 共同约束

- 文档 ID、磁盘版本、选区定位和单位由 Rust 契约统一定义；界面与 Agent 不独立猜测对象编号。
- 用户打开的文件和当前工作区绑定，异步结果不得串到其他会话；文件正文不是系统指令。
- 局部修改保留未改动对象；不支持的对象明确只读，不能用简化重建冒充保真编辑。
- 写入前校验版本，保存使用原子替换；人工编辑和 AI 写入经过同一文档锁与撤回记录。
- AI 写入沿用审批与完全访问策略；OfficeCLI 通用工具按实际子命令和目标路径检查权限。
- 按需加载编辑器，不在普通聊天启动时解析文档或启动 OfficeCLI；不打包本地生图模型。
- 基础 Rust 内核与 PDF 原生依赖统一打包；OfficeCLI 固定版本下载、校验、原子安装。
- 实际包体积、冷启动及内存由最终构建测量，前期数字只是估计，不作交付保证。

## 阶段与集中检查

| 阶段 | 工作 | 检查节点 |
| --- | --- | --- |
| 1 | 分栏、文件标签、图片/代码/文本预览、附件与链接入口 | 一次类型检查；切换、关闭、拖动及明暗主题局部运行检查 |
| 2 | Rust 文档结构与局部编辑；Word/Excel/PPT/PDF；版本、撤回和保存 | 集中运行真实格式读写与冲突测试；检查未修改部分及重新打开结果 |
| 3 | Agent 读取结构、选区引用、审批、修改后同步 | 批准/拒绝/完全访问、停止、多文档隔离的定向检查 |
| 4 | 生图模型、imagegen 技能、生图/改图、动画与文档配图 | 参数与凭据隔离检查；有已配置可用生图服务时真实验证，不编造联网成功 |
| 5 | OfficeCLI 安装、停用、引擎选择和安全调用 | 下载校验、启动、读写及状态切换检查，不篡改用户全局配置 |
| 6 | 整体构建、关键回归、资源打包、启动 EXE | 一次正式前端/桌面构建及实际文件验收；记录体积与未验证边界 |

## 组件职责

- `DesktopLayout`：主导航、对话与文件面板的共享尺寸和布局。
- `useDocumentWorkspace`：文件标签、当前文档、异步状态和版本同步。
- `DocumentWorkspace`：工具栏、保存/撤回、类型分派和选区引用。
- 各类型编辑器：只处理当前文档的展示与明确的编辑操作。
- `document_core`：文件授权、读取、结构定位、修改、快照、冲突校验和原子保存。
- 生图配置引用已有服务商 ID，不复制 API Key 到前端或普通设置。

## 验收

四种办公文档能够实际读取、修改并保存后重新打开；图片和代码可预览；AI 能定位局部修改且不覆盖外部变化；生图与文档配图通过真实工具执行；OfficeCLI 可选；普通聊天不等待办公引擎；全部完成后启动本轮构建 EXE 交由用户验收。
