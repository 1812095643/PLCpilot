# PLC 安全约束

## 程序语义

- 按循环扫描模型推理，不把 PLC 程序当作一次性脚本。
- 一个输出只允许存在一个最终写入者；跨 POU 写入必须先查清责任边界。
- 状态机必须有明确初始态、转换条件、超时和异常回退。
- 启动条件、停止条件、故障条件和复位条件分开表达。
- 互锁默认失效安全，通信中断、传感器异常和越界值不能导致危险输出被置位。

## 变更审查

- 定时器和计数器必须检查扫描周期及单位。
- 边沿触发需要确认实例生命周期，不能在每一扫描周期重新创建状态。
- 报警锁存与报警恢复必须明确，不能仅靠瞬时条件。
- 修改 I/O 映射、设备参数、下载、RUN/STOP、Reset、Force 必须单独审批。
