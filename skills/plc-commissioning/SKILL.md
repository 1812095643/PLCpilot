# PLC 投运与交付规则

1. 先确认工程版本、目标设备、任务周期、I/O 点表、通信路径和回退版本。
2. 把离线编译、仿真、现场下载、RUN/STOP、在线写变量和 Force/Unforce 作为独立阶段。
3. 默认只允许离线读取、静态分析和生成检查清单；下载、运行和在线修改必须由用户明确审批。
4. 每个修改都要记录原因、影响的 POU/DUT/GVL、验证步骤、预期报警和回退方式。
5. 任何安全互锁、急停、看门狗和通信失效策略都不能被自动移除或绕过。
6. 无法连接真实设备时，不得把仿真或静态检查结果描述为现场投运成功。
