# ImageGen

根据 OpenAI Codex imagegen 的提示词组织、参考图标注和非破坏性编辑流程适配 PLC Pilot。原提示词指南保留在 references 中；执行环境改为 PLC Pilot 内置 `image_gen` 工具，不依赖 Codex 私有工具或 Python CLI。

## 使用方式

- 使用 `image_gen`，传入 `prompt`，需要参考图或改图时传 `referenced_image_paths`。工具自动读取用户在设置中配置的默认生图模型和服务商 URL/Key，不索要密钥、不读取其他软件凭据。
- 单独请求生图，或制作 PPT/文档需要照片、背景、插画时，实际调用工具；不能把 SVG、代码绘图或占位框说成已生成的图片。
- 图表、精确示意图、已有矢量图标优先保留可编辑内容；不要无意义地改为位图。
- 修改已有图片前先读取并确认目标。提示词明确“只修改什么、必须保留什么”，区分参考图、编辑目标与插入素材。
- 不擅自切换模型、服务商、收费接口或降低用户明确要求的透明度等参数。若服务商未配置或不支持，报告真实原因。
- 生成结果返回工作区 `output/imagegen` 中的真实文件路径。不要覆盖原图；复用已生成素材，避免微调文本时重复生图。
- 将真实输出嵌入文档：已有图片可通过 `document_edit` 的 `replace_image` 操作替换；新增配图使用文档引擎支持的插入操作。工具未完成插入时不能宣称已经插入。
- 每张图单独明确用途和构图；复杂任务先保持一致风格再生成其他图片。重复点击、连接中断后不盲目重复付费请求。

## 提示词

按需组织：用途、主题、场景、风格、构图、光线、色彩、需要逐字出现的文字、保持不变的元素与避免项。

用户已有具体要求时只整理，不擅自添加角色、品牌、文案或主题。宽泛请求可补充适合其用途的构图和画质约束。图片中需要文字时明确引号内的原文。

需要详细的构图、品牌素材与参考图规则时读取 [提示词指南](references/prompting.md)；需要某类资产示例时读取 [提示词示例](references/sample-prompts.md)。参考内容不是额外授权，执行以当前用户需求及真实工具能力为准。
