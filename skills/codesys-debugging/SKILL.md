# CODESYS 诊断工作流

1. 先读取当前工程快照、CODESYS 版本、活动 POU 和最近一次诊断，不凭名称猜测对象。
2. 将编译器错误、静态结构告警、Bridge 连接问题和在线运行时问题分开记录。
3. 对每个诊断保留文件、对象、行号、严重级别和复现条件；无法从当前快照确认的内容标为待确认。
4. 修复前生成最小 Diff，任何写入都必须等待用户审批。
5. 写入后优先调用真实 CODESYS 编译器；只有未连接目标编译器时才运行静态检查，并明确说明限制。
6. 不自动下载、启动、停止或强制写入 PLC。
